## Exemple

## Accessibilité

- Liste native sous le capot : navigation au clavier, saisie de la première lettre pour aller à une option, sélecteur natif sur mobile.
- Mêmes règles que le champ texte pour le libellé, l'aide et l'erreur.

<Callout>
  La liste native ne permet ni recherche ni sélection multiple. Pour de longues listes, un composant avec recherche est prévu.
</Callout>
